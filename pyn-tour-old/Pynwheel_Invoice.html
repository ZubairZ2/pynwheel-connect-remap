Main changes included

iOS

  • CCommonCrypto / SwiftyJWT: SDK-specific SWIFT_INCLUDE_PATHS (iphoneos vs iphonesimulator) to fix "redefinition of module CCommonCrypto"; ensured module maps under SwiftyCrypto/CocoaPods for each SDK.
  • Swift explicit modules: Set SWIFT_ENABLE_EXPLICIT_MODULES = NO for the app target to resolve "Unable to find module dependency: _SwiftConcurrencyShims" with Xcode 26 / Swift 5.
  • RxBluetoothKit linker: Added -Wl,-U,_swift_coroFrameAlloc to OTHER_LDFLAGS so _swift_coroFrameAlloc resolves at load time from the Swift runtime.
  • SwiftyCrypto / SwiftyJWT: Existing Swift 5 compatibility patches (e.g. deallocate, enum cases) retained and verified.
  • CocoaPods: SelfTourTests ALWAYS_EMBED_SWIFT_STANDARD_LIBRARIES set to $(inherited) to clear CocoaPods override warning.
  • RNVectorIcons: Switched to autolinking (RN 0.60+) instead of explicit pod entry.

Android

  • Build configuration: Moved ext (buildToolsVersion, minSdkVersion, compileSdkVersion, targetSdkVersion) to top-level in root build.gradle; app build.gradle now uses rootProject.ext.buildToolsVersion.
  • Native modules: Added react-native-config and react-native-video to settings.gradle and app dependencies; added Teknasyon Maven repository for dependencies.
