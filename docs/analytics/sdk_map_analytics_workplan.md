# SDK Analytics — Work Plan (Revised)

## Core Philosophy

**SDK owns analytics. Rails stores it. React only tracks what React owns.**

The SDK already holds the session token from `_verifyPartner`. It intercepts every
SDK-native event internally (unit clicks, hover, zoom, floor, 3D). The React app
only calls `sdk.capture()` for its own UI events (filters, CTAs, modals).

Adding a new event type in future = add one line to the SDK or one `sdk.capture()` call
in React. Zero Rails migrations. Zero service changes. Zero new endpoints.

---

## Problems with the Previous Design

| Issue | Previous | Revised |
|---|---|---|
| React wires 30+ `track()` calls | React calls `track()` on every handler | SDK auto-captures SDK-native events |
| 3 HTTP endpoints per session | `track_activity` + `set_context` + `end_session` | Single `POST /events` batch |
| Per-event HTTP call | 1 fetch per user action | Queue + flush every 5s / on page hide |
| Metadata whitelist | `ALLOWED_METADATA_KEYS` array must be updated | Sanitizer: any `snake_case` key ≤ 50 chars |
| Separate analytics token | React manages its own auth for analytics | Reuses SDK's existing session token |
| Session end = separate endpoint | `PATCH /end_session` | `map_session_end` event in final batch |
| Device context = separate call | `POST /set_context` on load | Included in first batch payload automatically |

---

## Architecture Overview

```
User action
    │
    ├─ SDK-native event (unit click, zoom, floor, hover, 3D)
    │       └─ SDK intercepts internally → analytics.capture()
    │
    └─ React UI event (filter, CTA, modal, tab)
            └─ sdk.capture('bedroom_filter', 'click', { filter_bedroom: v })

analytics.capture()
    └─ queued in memory (JS array)
    └─ flush every 5s  OR  on visibilitychange=hidden (sendBeacon)
            └─ POST /api/partner/maps/events
                    { session_id, client_type, device_context?, events: [...] }

SdkController#track_events
    └─ SdkAnalyticsService#process_batch
            └─ find_or_create_session (by session_id + community_id)
            └─ for each event: increment JSONB counter, update interactions, visited_pages
            └─ if device_context present: set once on session
            └─ if map_session_end event: set end_datetime
            └─ session.save
```

## Service

```ruby
# app/services/analytics/sdk_analytics_service.rb
module Analytics
  class SdkAnalyticsService

    # "Map interactions" definition per client type.
    # To support a new client: add one line here. Nothing else changes.
    INTERACTION_EVENTS = {
      "web_map"    => %w[unit_marker_click apply_now_click save_favorite_click sent_favorite_click].to_set,
      "touch_map"  => %w[unit_marker_click apply_now_click save_favorite_click].to_set,
      "ipad_map"   => %w[unit_marker_click apply_now_click appointment_scheduled_click].to_set,
      "mobile_app" => %w[unit_marker_click apply_now_click save_favorite_click].to_set,
    }.freeze
    DEFAULT_INTERACTION_EVENTS = %w[unit_marker_click apply_now_click].to_set.freeze

    SESSION_START_EVENT = "map_load".freeze
    SESSION_END_EVENT   = "map_session_end".freeze

    VISITED_PAGES = {
      "map_load"   => "Map main page",
      "view_saved" => "View favorites page",
    }.freeze

    def initialize(community:, client_type:, session_id:, partner:, sdk_version: "v1")
      @community   = community
      @timezone    = community.get_time_zone
      @client_type = client_type
      @session_id  = session_id
      @partner     = partner
      @sdk_version = sdk_version
    end

    # Main entry point — called with a full batch of events from one flush.
    def process_batch(events:, device_context: nil)
      return if events.blank?

      session = nil

      events.each do |raw|
        name = raw["name"].to_s.strip
        type = raw["type"].to_s.presence || "click"
        meta = sanitize_metadata(raw["metadata"])

        # Session end: mark and skip further processing
        if name == SESSION_END_EVENT
          (session || find_current_session)&.update_column(:end_datetime, now)
          next
        end

        session ||= name == SESSION_START_EVENT ? create_session : find_or_create_session
        next unless session

        key = "#{name}_#{type}"
        increment_event(session, key)
        merge_event_metadata(session, meta)
        update_interactions(session, key)
        update_visited_pages(session, name)
      end

      if session && device_context.present?
        session.device_context = sanitize_context(device_context)
      end

      session&.save

    rescue StandardError => e
      Rails.logger.error("[SdkAnalyticsService#process_batch] #{e.class}: #{e.message}")
    end

    private

    ALLOWED_CONTEXT_KEYS = %w[
      device_type viewport_width viewport_height referrer
      user_agent sdk_version os_name os_version
      kiosk_id device_uuid app_version
    ].freeze

    def find_or_create_session
      last = find_current_session
      return create_session unless last
      session_idle?(last) ? create_session : last.tap { |s| s.updated_at = now }
    end

    def find_current_session
      SdkSession.where(
        community_id: @community.id,
        session_id:   @session_id,
        client_type:  @client_type
      ).order(:created_at).last
    end

    def create_session
      SdkSession.create!(
        community_id:              @community.id,
        client_type:               @client_type,
        session_id:                @session_id,
        partner:                   @partner,
        sdk_version:               @sdk_version,
        community_time_zone:       @timezone,
        start_datetime:            now,
        map_interactions:          0,
        map_interactions_last_active: now,
        events:                    {},
        device_context:            {},
        visited_pages:             []
      )
    end

    def increment_event(session, key)
      counts = session.events || {}
      counts[key] = (counts[key] || 0) + 1
      session.events = counts
    end

    def merge_event_metadata(session, metadata)
      return if metadata.blank?
      current = session.events || {}
      metadata.each do |k, v|
        # Arrays accumulate unique values (e.g. viewed_unit_ids)
        # Scalars: last-write-wins (e.g. current_floor)
        current[k] = v.is_a?(Array) ? ((current[k] || []) + v).uniq : v
      end
      session.events = current
    end

    def update_interactions(session, event_key)
      return unless interaction_event?(event_key)
      last = session.map_interactions_last_active&.in_time_zone(@timezone)
      return if last && !session_idle_at?(last)
      session.map_interactions = (session.map_interactions || 0) + 1
      session.map_interactions_last_active = now
    end

    def update_visited_pages(session, event_name)
      page = VISITED_PAGES[event_name]
      return unless page
      session.visited_pages = ((session.visited_pages || []) | [page])
    end

    def interaction_event?(event_key)
      (INTERACTION_EVENTS[@client_type] || DEFAULT_INTERACTION_EVENTS).include?(event_key)
    end

    def session_idle?(session)
      session_idle_at?(session.updated_at&.in_time_zone(@timezone))
    end

    def session_idle_at?(dt)
      return false unless dt
      ((now.to_datetime - dt.to_datetime) * 24 * 60).to_i >= ENV.fetch("IDLE_TIME_MAPS", 30).to_i
    end

    # Dynamic sanitizer — no whitelist. Any snake_case key ≤ 50 chars, value ≤ 300 chars.
    # Adding new metadata fields requires zero code changes.
    def sanitize_metadata(meta)
      return {} unless meta.is_a?(Hash)
      meta.each_with_object({}).with_index do |((k, v), out), idx|
        break out if idx >= 15
        key = k.to_s
        next unless key.match?(/\A[a-z_]{1,50}\z/)
        next unless [String, Integer, Float, TrueClass, FalseClass].include?(v.class)
        out[key] = v.is_a?(String) ? v.slice(0, 300) : v
      end
    end

    def sanitize_context(context)
      context.to_h.slice(*ALLOWED_CONTEXT_KEYS)
    end

    def now
      Time.now.in_time_zone(@timezone)
    end
  end
end
```

```ruby
# In SdkController — add to SESSION_ACTIONS, add before_action :load_community_from_session

ALLOWED_CLIENT_TYPES = %w[web_map touch_map ipad_map mobile_app partner_embed].freeze

# POST /api/partner/maps/events
# Called by SDK on every flush (every 5s + on page hide via sendBeacon)
def track_events
  session_id  = params[:session_id].to_s.strip
  return render_error("session_id is required.", 400) if session_id.blank?

  client_type = ALLOWED_CLIENT_TYPES.include?(params[:client_type]) ? params[:client_type] : "web_map"
  events      = Array(params[:events]).first(100)       # hard cap: 100 events per batch
  context     = params[:device_context]

  Analytics::SdkAnalyticsService.new(
    community:   @community,
    client_type: client_type,
    session_id:  session_id,
    partner:     @partner_name
  ).process_batch(events: events, device_context: context)

  head :no_content
end
```

## SDK Analytics Module (`pyn-map-sdk.js`)

Add `PynAnalytics` as a self-contained IIFE inside the SDK file before `PynMapSDKMethods`.

```js
// ─────────────────────────────────────────────────────────────────────────────
// PynAnalytics — internal, embedded analytics engine
// ─────────────────────────────────────────────────────────────────────────────
var PynAnalytics = (function () {

  function create(opts) {
    var s = {
      token:       opts.token,
      apiBase:     opts.apiBase,
      clientType:  opts.clientType || 'web_map',
      sdkVersion:  opts.sdkVersion || 'v1',
      sessionId:   _uuid(),
      queue:       [],
      contextSent: false,
      dead:        false
    };

    // Flush every 5s
    s.timer = setInterval(function () { _flush(s, false); }, 5000);

    // Flush on page hide (works for tab close, navigation, background)
    s._onHide = function () {
      if (document.visibilityState === 'hidden') {
        s.queue.push({ name: 'map_session_end', type: 'click', ts: Date.now() });
        _flush(s, true);
      }
    };
    document.addEventListener('visibilitychange', s._onHide);

    return {
      capture:   function (name, type, metadata) { _capture(s, name, type, metadata); },
      flush:     function (beacon)               { _flush(s, beacon); },
      sessionId: function ()                     { return s.sessionId; },
      destroy:   function () {
        s.dead = true;
        clearInterval(s.timer);
        document.removeEventListener('visibilitychange', s._onHide);
      }
    };
  }

  function _capture(s, name, type, metadata) {
    if (s.dead) return;
    s.queue.push({ name: name, type: type || 'click', metadata: _sanitize(metadata), ts: Date.now() });
    if (s.queue.length >= 20) _flush(s, false);
  }

  function _flush(s, beacon) {
    if (s.dead || !s.queue.length) return;
    var events = s.queue.splice(0);

    var body = {
      session_id:  s.sessionId,
      client_type: s.clientType,
      events:      events
    };

    if (!s.contextSent) {
      body.device_context = _context(s);
    }

    var url  = s.apiBase + '/api/partner/maps/events';
    var json = JSON.stringify(body);

    if (beacon && navigator.sendBeacon) {
      navigator.sendBeacon(url, new Blob([json], { type: 'application/json' }));
      s.contextSent = true;
      return;
    }

    fetch(url, {
      method:  'POST',
      headers: { 'Authorization': 'Bearer ' + s.token, 'Content-Type': 'application/json' },
      body:    json
    }).then(function () {
      s.contextSent = true;
    }).catch(function () {}); // fire-and-forget — analytics must never break the map
  }

  function _context(s) {
    var w = window.innerWidth;
    return {
      device_type:     w < 768 ? 'mobile' : w < 1024 ? 'tablet' : 'desktop',
      viewport_width:  window.innerWidth,
      viewport_height: window.innerHeight,
      referrer:        document.referrer || '',
      sdk_version:     s.sdkVersion,
      user_agent:      (navigator.userAgent || '').slice(0, 200)
    };
  }

  function _sanitize(meta) {
    if (!meta || typeof meta !== 'object') return {};
    var out = {}, n = 0;
    for (var k in meta) {
      if (n >= 15) break;
      if (!/^[a-z_]{1,50}$/.test(k)) continue;
      var v = meta[k];
      if (typeof v === 'string')  { out[k] = v.slice(0, 300); n++; }
      else if (typeof v === 'number' || typeof v === 'boolean') { out[k] = v; n++; }
    }
    return out;
  }

  function _uuid() {
    if (typeof crypto !== 'undefined' && crypto.randomUUID) return crypto.randomUUID();
    return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, function (c) {
      var r = Math.random() * 16 | 0;
      return (c === 'x' ? r : (r & 0x3 | 0x8)).toString(16);
    });
  }

  return { create: create };
})();
```

### Metadata fields

Any `snake_case` key is accepted. No whitelist. The sanitizer enforces:
- Key: `/^[a-z_]{1,50}$/`
- Value: string ≤ 300 chars, or number/boolean
- Max 15 keys per event

Common metadata used today:
```
viewed_unit_id        unit ID on marker click/hover
favorited_unit_id     unit ID on save favorite
```

## Analytics Dashboard Queries

```sql
-- Apply clicks
SELECT SUM((events->>'apply_now_click')::int) FROM sdk_sessions
WHERE community_id = :id AND client_type = 'web_map'

-- Sessions with any meaningful event
WHERE events != '{}'::jsonb

-- 3D map usage
WHERE (events->>'map_3d_click')::int > 0

-- Filter breakdown
SELECT
  SUM((events->>'bedroom_filter_click')::int)        AS bedroom,
  SUM((events->>'pricing_filter_click')::int)        AS pricing,
  SUM((events->>'availability_filter_click')::int)   AS availability
FROM sdk_sessions WHERE ...

-- Device breakdown
SELECT device_context->>'device_type' AS device, COUNT(*)
FROM sdk_sessions WHERE community_id = :id GROUP BY 1

-- Client type comparison (web vs touch vs iPad)
SELECT client_type, COUNT(*), SUM(map_interactions)
FROM sdk_sessions WHERE community_id = :id GROUP BY client_type

-- New event added (e.g. floorplan hover) — query immediately, no migration
WHERE (events->>'floorplan_hover')::int > 0
```

## Extensibility — How to Add Things Later

**New event type** (e.g. a new button in React):
- Add one `sdk.capture('new_event', 'click')` call. Done.
- No Rails changes. Data appears in `events` JSONB immediately.

**New metadata field** (e.g. `unit_floor`):
- Add to metadata object: `sdk.capture('unit_marker', 'click', { viewed_unit_id: id, unit_floor: floor })`.
- Sanitizer accepts it automatically. No Rails changes.

**New client type** (e.g. Touch SDK):
- SDK init: `clientType: 'touch_map'`
- Add to `INTERACTION_EVENTS["touch_map"]` in service. One line.
- Touch-specific events go into same JSONB. Same table. Same queries.

**New device context field** (e.g. `screen_dpi`):
- Add to `ALLOWED_CONTEXT_KEYS` in service. One line.

**New analytics chart**:
- Write a SQL query using JSONB operators. No migration.
