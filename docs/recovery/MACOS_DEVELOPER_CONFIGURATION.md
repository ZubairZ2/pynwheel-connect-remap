| File | Role |
|---|---|

| `~/.zshrc` | oh-my-zsh (`ZSH_THEME="powerlevel10k/powerlevel10k"`, plugins `git zsh-autosuggestions zsh-syntax-highlighting autojump`), `PROMPT='%/ %# '`, sources `~/.p10k.zsh`, adds `$HOME/go/bin` and `$HOME/.local/bin` to PATH, ends with `eval "$(rbenv init - zsh)"` |

| `~/.oh-my-zsh/custom/plugins/{zsh-autosuggestions,zsh-syntax-highlighting}`, `custom/themes/powerlevel10k` | git clones of the three add-ons |

Restore:

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
git clone https://github.com/zsh-users/zsh-autosuggestions ~/.oh-my-zsh/custom/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting ~/.oh-my-zsh/custom/plugins/zsh-syntax-highlighting
git clone --depth=1 https://github.com/romkatv/powerlevel10k ~/.oh-my-zsh/custom/themes/powerlevel10k
brew install autojump
cp "$BK/04_dotfiles/home/.zshrc" "$BK/04_dotfiles/home/.zprofile" "$BK/04_dotfiles/home/.p10k.zsh" "$BK/04_dotfiles/home/.profile" "$BK/04_dotfiles/home/.zlogin" ~/
brew install --cask font-meslo-lg-nerd-font     # the prompt font (cask was installed)
```

The `.zshrc` references rbenv and the `.profile`/`.zlogin` reference RVM; install both before opening a
new terminal or the lines fail harmlessly.

## Raycast

Raycast 1.104.32, installed from the direct download (`/Applications/Raycast.app`; it is not a Homebrew
cask on this machine). Onboarding is complete and the global hotkey is set (the default ⌥ Space unless
changed in Settings → General [VERIFY]). Its data (extensions, quicklinks, snippets, aliases, hotkeys)
lives in an **encrypted SQLite store** under `~/Library/Application Support/com.raycast.macos/`
(500 MB, mostly the bundled Node runtime and update cache) that cannot be copied between machines. No
Store extensions directory was found, so the installed extension set is **[VERIFY] in the app**.

The supported backup is the in-app export, which only you can run:

1. Raycast → Settings (⌘,) → **Advanced** → **Export Settings & Data** → save the `.rayconfig` file
   (optionally with a password) into `~/Desktop/PYNWHEEL_PRE_WIPE_BACKUP_2026-10-30/04_dotfiles/raycast/`.
2. After the wipe: download Raycast (`brew install --cask raycast` or https://raycast.com), open it,
   Settings → Advanced → **Import Settings & Data**, pick the file. If a Raycast account with Cloud Sync
   is in use, signing in restores the same data **[VERIFY]**.

`com.raycast.macos.plist` (hotkeys and preference flags) is copied automatically; it is a convenience,
not a substitute for the export.
