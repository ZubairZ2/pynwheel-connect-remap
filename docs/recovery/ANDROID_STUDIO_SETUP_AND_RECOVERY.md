## Reinstalling after the wipe

1. **Android Studio**: download the current stable from https://developer.android.com/studio (2026.2
   was in use; a newer stable also opens the project). Drag to `/Applications`, open, choose "Do not
   import settings" (or import the backup's `options/` through File → Manage IDE Settings → Import
   Settings after first launch), run the setup wizard with the **Standard** profile. It installs the latest
   platform, build-tools, platform-tools and the emulator into `~/Library/Android/sdk`.
2. **SDK components** (Settings → Languages & Frameworks → Android SDK, or the command line after
   installing command-line tools in the "SDK Tools" tab):
   ```bash
   SDK=~/Library/Android/sdk
   "$SDK/cmdline-tools/latest/bin/sdkmanager" "platforms;android-36" "build-tools;36.0.0" "platform-tools" "emulator" "sources;android-36"
   # optional, matching the old machine exactly:
   "$SDK/cmdline-tools/latest/bin/sdkmanager" "platforms;android-34" "platforms;android-28" "build-tools;35.0.0" "build-tools;34.0.0"
   yes | "$SDK/cmdline-tools/latest/bin/sdkmanager" --licenses
   ```
3. **Gradle JDK**: Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK →
   "Download JDK" → version 21 (vendor JetBrains Runtime, as before, or Temurin). This creates
   `~/Library/Java/JavaVirtualMachines/<jdk>` again. For command-line builds export it:
   ```bash
   export JAVA_HOME=$(/usr/libexec/java_home -v 21)
   ```
4. **Environment** (optional, for `adb` on PATH; nothing in the project requires it):
   ```bash
   cat >> ~/.zshrc <<'EOT'
   export ANDROID_HOME="$HOME/Library/Android/sdk"
   export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH"
   EOT
   ```
5. **Secrets**: `cp "$BK/01_secrets/home/.gradle/gradle.properties" ~/.gradle/` (the igloohome token);
   `cp "$BK/01_secrets/home/.android/"{adbkey,adbkey.pub,debug.keystore} ~/.android/` (keeps the
   phone's USB-debugging authorisation and the same debug signature, so the installed APK updates in place).
6. **Phone**: enable Developer options → USB debugging on the A02s, connect, `adb devices -l`; accept the
   prompt on the phone if the ADB key changed.
7. **Settings and plugins**: no third-party plugins were installed. Import the saved `options/` if the
   editor preferences matter (font, color scheme, recent projects).

## Rebuilding the Tour App APK (verified sequence from this machine)

```bash
cd ~/pynwheel-staging/tour-app
npm ci                                                        # or npm install
# where the app talks to: .env.production.local (ignored, in 01_secrets/repo/tour-app/) holds
#   VITE_TOUR_API_URL=http://<this Mac's LAN IP>:3000   for a LAN build against local Rails, or
#   VITE_TOUR_API_URL=https://pyn-system-16a05cad79df.herokuapp.com   for the staging build
ipconfig getifaddr en0                                        # the LAN IP moves between networks: fix it before every LAN build
npm run build                                                 # tsc --noEmit + vite build -> dist/
npx cap sync android                                          # copies dist/ and regenerates capacitor.settings.gradle
cd android
JAVA_HOME="$HOME/Library/Java/JavaVirtualMachines/jbr-21.0.11/Contents/Home" ./gradlew assembleDebug
ls -l app/build/outputs/apk/debug/app-debug.apk               # the output
~/Library/Android/sdk/build-tools/36.0.0/aapt2 dump badging app/build/outputs/apk/debug/app-debug.apk | head -3
~/Library/Android/sdk/platform-tools/adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- Debug builds are signed with `~/.android/debug.keystore`; the `allowMixedContent` / cleartext flags are
  on only when `VITE_TOUR_API_URL` is plain `http://` (see `capacitor.config.ts`).
- **Release** builds: `./gradlew assembleRelease` produces an unsigned APK; no release keystore or
  `signingConfig` exists for `com.pynwheel.tour` yet (the only release keystore on the Mac is the legacy
  app's `selftour-key.keystore`). Creating one is a separate decision; store it with the secrets.
- Historical APKs (October 19–29) are in `artifacts/` (ignored; copied to `02_local_docs_and_design/artifacts/`).
- Alternative: `npm run cap:android` opens the project in Android Studio; Build → Build APK(s).
